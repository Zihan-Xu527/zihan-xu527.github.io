# Zihan Xu — Academic Website

Source for [zihanxu.com](https://zihanxu.com), the academic website of Zihan Xu.

The site is a lightweight, accessible static website hosted with GitHub Pages. Its content is maintained alongside Zihan's master academic CV.

## Updating the site

- Edit `index.html` for content.
- Edit `styles.css` for presentation.
- Replace `assets/Zihan_Xu_CV.pdf` when the CV changes.

Project-specific repository links will be added after the corresponding research code is prepared for public release.
